# Sliding Window

## Теория

Окно фиксированного или переменного размера, скользящее по массиву/строке. Вместо пересчёта с нуля — добавляешь новый элемент справа, убираешь старый слева.

### Два типа

**Фиксированное окно** — размер задан (k). Сдвигаешь на 1 позицию: вычитаешь ушедший, прибавляешь пришедший.

**Динамическое окно** — размер меняется. right расширяет, left сужает пока выполняется условие. Для поиска минимального/максимального подмассива.
